# Continental Virtual Hockey League Website

Public website: https://noflow.github.io/CVHL/

This repository was renamed from TTHL when that league retired. Its previous website remains available in Git history.

The CVHL website is generated from the shared API-Toolbox website template and the toolkit configuration for `continental-virtual-hockey-league`.

In the toolkit, open **CVHL > Website**, sync teams, build the website, and download the website ZIP. Publish the generated files to this repository's `main` branch.

The website reads CVHL's dedicated roster spreadsheet directly. Edit player names, salaries, and staff roles in its **Roster** tab; keep signed players in **Roster** and training-camp players in **TC**. Changes appear when visitors refresh the website. Team-list or website-settings changes require rebuilding and publishing the package.

The eight current teams are BOS, BUF, DAL, DET, LAK, NYR, SEA, and UTA. Their logos are included in `images`.
